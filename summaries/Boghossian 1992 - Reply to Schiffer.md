# Boghossian 1992 - Reply to Schiffer

**Raw source:** [[raw_sources/Boghossian-1992-Reply to Schiffer-Philosophical Issues.pdf|PDF]] · **Converted Markdown:** [[converted_markdown/Boghossian-1992-Reply to Schiffer-Philosophical Issues|Converted Markdown]]

## Abstract

Boghossian defends his slow-switching thought experiment against Stephen Schiffer's critique in the same volume. In "Externalism and Inference," Boghossian argued that a thinker transported between Earth and Twin Earth without internal indication (Peter) would have cohabiting Earthly and Twin Earthly contents and would consequently be led into inferences that appear valid from an introspective, a priori standpoint but are objectively invalid under an externalist semantics. Boghossian replies to two challenges raised by Schiffer. First, in response to Schiffer's worry that beliefs expressed by public names do not essentially involve names in thought, Boghossian argues that Peter's extensive knowledge of Pavarotti resists descriptive replacement, and that the externalist dilemma applies equally to general natural-kind terms like 'water' whose memory tokens trace back to distinct causal environments. Second, against Schiffer's claim that tokens of 'Pavarotti' across premises must retain the same semantic value, Boghossian argues that externalist causal principles fix memory contents to their original environments, allowing a thinker to combine an Earthly memory with a Twin Earthly memory. To show that this difficulty does not depend on identity claims, Boghossian formulates a non-identity case in which Peter erroneously concludes that Pavarotti swore falsely, confirming that externalism entails that invalid deductive reasoning can be introspectively indistinguishable from valid inference.
Source: pp. 39-42.

## Main Summary

Boghossian clarifies the core thesis of his slow-switching case: in Peter, Earthly and Twin Earthly contents cohabit without internal indication (p. 39). While Kripke's Pierre showed that externalism allows inferences that are valid without appearing valid a priori, Peter's case establishes that externalism leads to inferences that look valid a priori but are invalid (p. 39).

Replying to Schiffer, Boghossian notes that Schiffer concedes content cohabitation, but questions whether Peter's beliefs essentially involve names in thought (pp. 39–40). Boghossian counters that Peter's knowledge of Pavarotti resists descriptive replacement, and that the argument applies equally to natural-kind terms like 'water' (pp. 41–42). Because externalist memory semantics traces content to original causal environments, Peter holds memory beliefs referring to water and others referring to twater (p. 41).

Boghossian also rejects Schiffer's claim that tokens of 'Pavarotti' across premises must share identical semantic values (p. 42). A thinker can combine an Earthly memory belief with a Twin Earthly memory belief to draw an invalid conclusion (p. 42). In a non-identity case, Peter learns on Twin Earth that Twin Pavarotti swore never to have visited New Zealand, and combines this with his Earthly memory of Pavarotti at Lake Taupo to infer that Pavarotti swore falsely (p. 42). Because the premises equivocate between distinct referents, the inference is invalid, undermining the transparency of validity (p. 42).

### Non-Identity Equivocation Defense Against Externalist Logical Transparency *(pp. 41–42)*

1. Some mental states have contents that constitutively depend on external environmental factors.
2. If some mental states have contents that constitutively depend on external environmental factors, then the semantic contents of memory beliefs are fixed by the causal environments of their original acquisition.
3. If the semantic contents of memory beliefs are fixed by the causal environments of their original acquisition, then possibly, a slow-switched thinker combines an Earthly memory belief and a Twin-Earth memory belief in a non-identity inference that appears valid a priori yet commits an undetectable equivocation.
4. If possibly, a slow-switched thinker combines an Earthly memory belief and a Twin-Earth memory belief in a non-identity inference that appears valid a priori yet commits an undetectable equivocation, then it is not the case that every thinker can know a priori the logical validity or invalidity of every concrete wide-content inference that thinker performs.
5. The semantic contents of memory beliefs are fixed by the causal environments of their original acquisition.
6. Possibly, a slow-switched thinker combines an Earthly memory belief and a Twin-Earth memory belief in a non-identity inference that appears valid a priori yet commits an undetectable equivocation.
7. Therefore, it is not the case that every thinker can know a priori the logical validity or invalidity of every concrete wide-content inference that thinker performs.
