# Two-Concept Originary Fixation Memory Definition (`D-21`)

## Formulation
Content-preserving memory across slow switching denotes originary environmental fixation and two-concept cohabitation in which slow switching adds a second concept while memory retains the originary concept.

## Explanation
Under this standard model of slow switching, when a thinker like Peter is unknowingly moved from Earth to Twin Earth and stays long enough to acquire a new Twin-Earth concept (such as "twater" or Twin Pavarotti), their memory faithfully preserves the original Earth concept alongside the new one under the same word. Because both concepts coexist in the mind without the thinker noticing, drawing an inference from an old Earth memory and a new Twin-Earth perception produces an undetectable equivocation—making this definition the engine behind most slow-switching arguments and a defining conjunct of [[Two-Concept Content Externalism]] (`P-41`).

## Usage in Literature

This two-concept model is the orthodox slow-switching account across the corpus: [[Paul Boghossian]] ([[Boghossian 1992 - Externalism and Inference]]), [[Sanford C. Goldberg]] ([[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification]], [[Goldberg-2008-Must Differences in Cognitive Value be Transparent]]), [[Jessica Brown]] ([[Brown 2004 - Anti-Individualism and Knowledge]]), [[John M.
