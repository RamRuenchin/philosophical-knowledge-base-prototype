# Narrow Fregean Cognitive Value Definition (`D-34`)

## Formulation
Cognitive value denotes a narrow, individualistically individuated Fregean mode of presentation that supervenes on factors internal to the thinker and governs first-order rational relations among thoughts.

## Explanation
In Gottlob Frege's philosophy of mind, "cognitive value" is the aspect of a thought's meaning that explains why someone can rationally believe one statement about an object while doubting another statement about the very same object (a "mode of presentation"). On this narrow internalist definition, cognitive value depends solely on internal first-order psychological dispositions inside the thinker—not on external social or physical facts, and not on higher-order reflective access—a view Brie Gertler defends using Tyler Burge's arthritis thought experiment (where actual Bert and counterfactual Bert are internally identical but belong to communities that use "arthritis" differently), contrasting with [[Social-Externalist Public Cognitive Value Definition]] (`D-35`) and [[Non-Fregean Wide Content Individuation Definition]] (`D-36`).

**Defines:** [[Cognitive Value]] (`C-10`)

## Usage in Literature

[[Brie Gertler]] endorses `D-34` in [[Gertler 2015 - Internalism, Externalism, and Accessibilism]], decoupling narrow Fregean cognitive value from higher-order accessibilism and arguing via a qualified Differential Dubitability criterion applied to Burge's arthritis case that cognitive value is narrow (Differential Dubitability Argument for Narrow Cognitive Value ([[Gertler 2015 - Internalism, Externalism, and Accessibilism#Arguments]]); Content Internalism About Cognitive Value Holds ([[Gertler 2015 - Internalism, Externalism, and Accessibilism#Propositions]])). By contrast, [[Sanford C. Goldberg]] in [[Goldberg-2008-Must Differences in Cognitive Value be Transparent]] and [[Tyler Burge]] reject purely individualistic individuation of cognitive value, contending that semantic deference and testimony anchor even Fregean cognitive value partly in public linguistic standards (`D-35`).
