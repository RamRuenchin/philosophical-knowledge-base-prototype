# Univocality of Referential Intent Secures Deductive Validity (`P-56`)

## Formulation

If content-preserving memory across slow switching denotes anaphoric preservative memory that keeps concept tokens univocal across deductive inference, then it is not the case that (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents).

## Explanation

In slow-switching puzzles like Boghossian's Peter case (`P-46`), an unwitting traveler from Earth to Twin Earth combines a pre-switch Earth memory with a post-switch Twin-Earth perception in what feels like a single deductive syllogism. This thesis states that if [[Content-Preserving Memory and Slow-Switching Dynamics|content-preserving memory]] works *anaphorically*—meaning that because the thinker intends to reason about one and the same individual or substance throughout, later concept tokens inherit the reference of earlier ones so all tokens stay univocal (keep a single uniform meaning)—then Peter does not commit an introspectively undetectable equivocation between distinct environmentally determined ("wide") contents (`P-47`).

## Usage in Literature

[[Stephen Schiffer]] introduces and endorses `P-56` in [[Schiffer 1992 - Boghossian on Externalism and Inference]] (via `ARG-06`), using the Yolanda identical-twins analog and single-premise conjoined restatement to argue that a thinker intending to refer to the same individual across premises fixes a uniform semantic value (or shared confused dossier) and passes it by semantic inheritance to derived tokens, thereby blocking slow-switch equivocation (`P-47`). [[Tyler Burge]] similarly endorses this anaphoric, univocality-preserving strategy (reconstructed across [[Boghossian 2011 - The transparency of mental content revisited]] and [[Goldberg 1999 - The Relevance of Discriminatory Knowledge of Content]]). [[Sanford C. Goldberg]] accepts `P-56` in [[Goldberg 1999 - The Relevance of Discriminatory Knowledge of Content]] as sufficient to secure formal deductive validity, while arguing that stipulating univocity fails to solve truth-directed reasoning problems like Sally's and later showing in [[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification]] that it shifts premise content and weakens justification. [[Paul Boghossian]] rejects `P-56` in [[Boghossian 1992 - Reply to Schiffer]], arguing that externalist causal principles fix independent memory beliefs to their originating environments even when combined in a non-identity inference.
