# Anaphoric Univocality-Preserving Memory Definition (`D-22`)

## Formulation
Content-preserving memory across slow switching denotes anaphoric preservative memory that keeps concept tokens univocal across deductive inference.

## Explanation
On this Tyler Burge- and Stephen Schiffer-inspired model, memory works "anaphorically"—like a pronoun referring back to an earlier noun—by locking later uses of a concept inside a deductive inference onto the exact same meaning as earlier premise tokens (or honoring the thinker's intention to refer to one and the same thing). By keeping the meaning unified ("univocal") across premises, this mechanism aims to stop slow-switched thinkers like Peter from accidentally equivocating between Earth and Twin-Earth concepts, though critics doubt it can smoothly handle premises formed independently in two different environments.

**Defines:** [[Content-Preserving Memory and Slow-Switching Dynamics]] (`C-05`)

## Usage in Literature

[[Stephen Schiffer]] endorses `D-22` in [[Schiffer 1992 - Boghossian on Externalism and Inference]] (invoking `ARG-06` alongside univocal referential intent `P-56` to block Peter's equivocation `P-47`), and [[Tyler Burge]]'s preservative-memory strategy is reconstructed under `D-22` across [[Boghossian 1992 - Reply to Schiffer]], [[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification]], [[Brown 2004 - Anti-Individualism and Knowledge]], and [[Collins 2008 - Content Externalism and Brute Logical Error]]. [[Manuel Pérez Otero]] also notes anaphoric preservation as a live externalist option in [[Otero 2012 - Boghossian's Inference Argument against Content Externalism Reversed]], while Boghossian, Goldberg, Brown, and Collins argue it fails to handle cross-contextual or synchronic memory retrieval without begging the question, with Goldberg's content-preservation dilemma ([[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification#Arguments]]) further arguing that its content-shifting univocality violates memorial justification preservation (`I2`).
