# Schiffer Univocal Intent Blocks Slow-Switch Equivocation (`ARG-06`)

## Formulation

- **Inconsistent literal set:** `¬ (P-56 ∧ D-22 ∧ P-47)`

- **Asserted (`P-56`):** [[Univocality of Referential Intent Secures Deductive Validity]] — If content-preserving memory across slow switching denotes anaphoric preservative memory that keeps concept tokens univocal across deductive inference, then it is not the case that (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents).
- **Asserted (`D-22`):** [[Anaphoric Univocality-Preserving Memory Definition]] — Content-preserving memory across slow switching denotes anaphoric preservative memory that keeps concept tokens univocal across deductive inference.
- **Asserted (`P-47`):** [[Peter Commits Undetectable Equivocation]] — If a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.

## Explanation

In Boghossian's slow-switching puzzle, Peter moves unknowingly from Earth to Twin Earth and combines an older memory with a newer perception in a single syllogism. If memory in reasoning works "anaphorically"—linking later occurrences of a term back to the same concept so the thinker's intention to talk about one single person or substance keeps the meaning uniform across both premises—then the syllogism stays logically valid (even if one premise turns out false). That directly rules out the claim that Peter commits an undetectable equivocation between two different meanings.

## Usage in Literature

### Classical Argument

[[Stephen Schiffer]] (`A-02`; [[Schiffer 1992 - Boghossian on Externalism and Inference]], pp. 32–36)—subsequently developed by [[Tyler Burge]] (`A-05`; discussed in [[Boghossian 2011 - The transparency of mental content revisited]] and [[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification]])—uses Ralph's identical-twins (`Yolanda`) counter-case and Peter's willingness to conjoin his premises ("Pavarotti once swam in Lake Taupo and is the singer I heard yesterday") to reject [[Peter Commits Undetectable Equivocation]] (`P-47`), supporting [[Peter Inference Remains Univocal via Anaphoric Memory]] (`P-49`):

1. Content-preserving memory across slow switching denotes anaphoric preservative memory that keeps concept tokens univocal across deductive inference.
2. If content-preserving memory across slow switching denotes anaphoric preservative memory that keeps concept tokens univocal across deductive inference, then it is not the case that (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents).
3. Therefore, it is not the case that (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents).

### Premise Rejections and Replies

- **Rejecting `D-22` and `P-56` (Independently grounded memories and premise-order absurdity):** [[Paul Boghossian]] (`A-01`; [[Boghossian 1992 - Reply to Schiffer]], pp. 41–42; [[Boghossian 2011 - The transparency of mental content revisited]], p. 460), [[Jessica Brown]] (`A-12`; [[Brown 2004 - Anti-Individualism and Knowledge]], pp. 177–179), and [[John M. Collins]] (`A-13`; [[Collins 2008 - Content Externalism and Brute Logical Error]], pp. 562–565) uphold `P-47` and reject anaphoric memory (`D-22`) in favor of [[Two-Concept Originary Fixation Memory Definition]] (`D-21`). They object that anaphoric links fail for non-identity combinations of independently grounded memories (such as Earth-Pavarotti at Lake Taupo plus Twin-Pavarotti swearing never to have visited New Zealand) and `water`/`twater` inferences, make thought content absurdly sensitive to the arbitrary order in which premises are entertained, and merely relocate equivocation into the lambda-abstraction step linking independently formed beliefs.
- **Epistemic-cost qualification (Shifting the cost from validity to memory):** [[Sanford C. Goldberg]] (`A-06`; [[Goldberg 1999 - The Relevance of Discriminatory Knowledge of Content]]; [[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification]]) grants `P-56` as a coherent option for anti-individualists, while arguing that taking `D-22` merely shifts the epistemic failure from deductive invalidity (`I1`) to memory-induced content shift and justification loss (`I2`; see Content-Preservation Dilemma Against Reflective Discursive Justification ([[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification#Arguments]]), Discursive Justification Horn Inconsistency (I1 vs. I2) ([[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification#Arguments]]), and Sally DKC Relevance Argument ([[Goldberg 1999 - The Relevance of Discriminatory Knowledge of Content#Arguments]])).
