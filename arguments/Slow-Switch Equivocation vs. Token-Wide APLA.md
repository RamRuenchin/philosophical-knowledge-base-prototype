# Slow-Switch Equivocation vs. Token-Wide APLA (`ARG-03`)

## Formulation

- **Inconsistent literal set:** `¬ (P-46 ∧ P-47 ∧ P-114 ∧ P-21)`

- **Asserted (`P-46`):** [[Boghossian Peter Slow-Switching Setup Possibility]] — Possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise.
- **Asserted (`P-47`):** [[Peter Commits Undetectable Equivocation]] — If a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.
- **Asserted (`P-114`):** [[Bridge - Undetectable Equivocation Defeats Token-Wide APLA]] — If both (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise) and (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents), then it is not the case that every thinker can know a priori the logical validity or invalidity of every concrete wide-content inference that thinker performs.
- **Asserted (`P-21`):** [[Token-Level Wide APLA Holds]] — Every thinker can know a priori the logical validity or invalidity of every concrete wide-content inference that thinker performs.

## Explanation

Suppose a thinker unknowingly moved between Earth and Twin Earth can perform a syllogism that seems completely valid from the inside while secretly trading on two distinct environment-dependent ("wide") concepts. Then the inference is actually invalid by equivocation, yet the thinker has no way to detect that invalidity from reflection alone. That directly collides with token-level wide a priori logical ability (APLA)—the claim that thinkers can always tell from the armchair whether any particular wide-content inference they perform is logically valid or invalid.

## Usage in Literature

### Classical Argument

[[Paul Boghossian]] (`A-01`; [[Boghossian 1992 - Externalism and Inference]], pp. 21–23; [[Boghossian 1994 - The Transparency of Mental Content]], pp. 44–46) derives `¬P-21` conditionally from two-concept externalism (`ARG-01`) as an objection to externalism. [[Manuel Pérez Otero]] (`A-03`; [[Otero 2012 - Boghossian's Inference Argument against Content Externalism Reversed]], pp. 162–167) and [[Paulo Faria]] (`A-14`; [[Faria 2009 - Unsafe reasoning A survey]], pp. 3–5, 11–13) accept the refutation of [[Token-Level Wide APLA Holds]] (`P-21`) while retaining [[Form-Level APLA Holds]] (`P-22`, under `D-10`) and [[Externalism Is Compatible with Logical-Luck Rationality]] (`P-28`):

1. Possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise.
2. If a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.
3. If both (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise) and (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents), then it is not the case that every thinker can know a priori the logical validity or invalidity of every concrete wide-content inference that thinker performs.
4. Both (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise) and (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents).
5. Therefore, it is not the case that every thinker can know a priori the logical validity or invalidity of every concrete wide-content inference that thinker performs.

### Premise Rejections and Replies

- **Rejecting `P-47` (Anaphoric univocality):** As reconstructed in [[Otero 2012 - Boghossian's Inference Argument against Content Externalism Reversed]] (pp. 163–165), [[Stephen Schiffer]] (`A-02`; [[Schiffer 1992 - Boghossian on Externalism and Inference]]) and [[Tyler Burge]] (`A-05`) reject undetectable equivocation (`P-47`) via anaphoric preservative memory ([[Schiffer Univocal Intent Blocks Slow-Switch Equivocation]], `ARG-06`), blocking the counterexample to `P-21`.
- **Rejecting `P-47` (Single-context weighting):** [[Henry Jackman]] (`A-07`; [[Jackman 2015 - Externalism, metasemantic contextualism, and self-knowledge]]) similarly rejects `P-47` via Jackman Single-Context Refutation of Peter Equivocation ([[Jackman 2015 - Externalism, metasemantic contextualism, and self-knowledge#Arguments]]).
