# Slow-Switching Equivocation Derivation (`ARG-01`)

## Formulation

- **Inconsistent literal set:** `¬ (P-41 ∧ P-46 ∧ P-63 ∧ ¬P-47)`

- **Asserted (`P-41`):** [[Two-Concept Content Externalism]] — Both some mental states have contents that constitutively depend on external environmental factors and slow switching produces two-concept cohabitation with originary memory fixation.
- **Asserted (`P-46`):** [[Boghossian Peter Slow-Switching Setup Possibility]] — Possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise.
- **Asserted (`P-63`):** [[Bridge - Two-Concept Externalism Yields Slow-Switch Equivocation]] — If both (both some mental states have contents that constitutively depend on external environmental factors and slow switching produces two-concept cohabitation with originary memory fixation) and (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise), then if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.
- **Negated (`~P-47`):** [[Peter Commits Undetectable Equivocation]] — It is not the case that if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.

## Explanation

Suppose what our thoughts mean depends partly on the external environment, and suppose someone (Peter) is unknowingly moved from Earth to Twin Earth long enough to acquire new local concepts while his older memories stay tied to Earth. When Peter combines an Earth memory with a Twin-Earth perception in a simple syllogism, the reasoning looks perfectly valid from the inside even though the middle term secretly refers to two different things. Those assumptions therefore collide with denying that Peter commits an undetectable equivocation.

## Usage in Literature

### Classical Argument

[[Paul Boghossian]] (`A-01`; [[Boghossian 1992 - Externalism and Inference]], pp. 18–22; [[Boghossian 1994 - The Transparency of Mental Content]], pp. 38–40, 45–46) assumes [[Two-Concept Content Externalism]] (`P-41`) conditionally for *reductio* to feed `P-47` into [[Slow-Switch Equivocation vs. Transparency of Difference]] (`ARG-02`) and [[Slow-Switch Equivocation vs. Token-Wide APLA]] (`ARG-03`). [[Jessica Brown]] (`A-12`; [[Brown 2004 - Anti-Individualism and Knowledge]], pp. 166–182) and [[John M. Collins]] (`A-13`; [[Collins 2008 - Content Externalism and Brute Logical Error]], pp. 555–571) endorse all three premises unconditionally from inside anti-individualism (after refuting displacement `D-23`, amalgamation `D-24`, anaphoric `D-22`, and enthymematic blocking strategies):

1. Both some mental states have contents that constitutively depend on external environmental factors and slow switching produces two-concept cohabitation with originary memory fixation.
2. Possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise.
3. If both (both some mental states have contents that constitutively depend on external environmental factors and slow switching produces two-concept cohabitation with originary memory fixation) and (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise), then if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.
4. Both (both some mental states have contents that constitutively depend on external environmental factors and slow switching produces two-concept cohabitation with originary memory fixation) and (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise).
5. Therefore, if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.

### Premise Rejections and Replies

- **Rejecting `P-41` (Anaphoric univocality instead of originary fixation):** [[Stephen Schiffer]] (`A-02`; [[Schiffer 1992 - Boghossian on Externalism and Inference]], pp. 32–36) and [[Tyler Burge]] (`A-05`; discussed in [[Boghossian 2011 - The transparency of mental content revisited]] and [[Goldberg-2007-Anti-Individualism, Content Preservation, and Discursive Justification]]) reject the originary memory-fixation conjunct of `P-41` (`D-21`) in favor of [[Anaphoric Univocality-Preserving Memory Definition]] (`D-22`), arguing independently in [[Schiffer Univocal Intent Blocks Slow-Switch Equivocation]] (`ARG-06`) that Peter's univocal referential intention prevents equivocation (`~P-47`).
- **Rejecting `P-63` (Single-context metasemantic weighting):** [[Henry Jackman]] (`A-07`; [[Jackman 2015 - Externalism, metasemantic contextualism, and self-knowledge]]) grants the setup (`P-46`) but denies that slow switching produces equivocation inside a single reasoning context, arguing independently in Jackman Single-Context Refutation of Peter Equivocation ([[Jackman 2015 - Externalism, metasemantic contextualism, and self-knowledge#Arguments]]) that one contextual weighting fixes a single content across both premises (`~P-47`).
