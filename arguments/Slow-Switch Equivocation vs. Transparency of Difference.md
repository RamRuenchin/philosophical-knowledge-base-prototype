# Slow-Switch Equivocation vs. Transparency of Difference (`ARG-02`)

## Formulation

- **Inconsistent literal set:** `¬ (P-46 ∧ P-47 ∧ P-64 ∧ P-11)`

- **Asserted (`P-46`):** [[Boghossian Peter Slow-Switching Setup Possibility]] — Possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise.
- **Asserted (`P-47`):** [[Peter Commits Undetectable Equivocation]] — If a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.
- **Asserted (`P-64`):** [[Bridge - Undetectable Equivocation Defeats TDC]] — If both (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise) and (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents), then it is not the case that every thinker can know a priori, for every two different-content thought tokens of that thinker, that they differ in content.
- **Asserted (`P-11`):** [[Transparency of Difference of Content]] — Every thinker can know a priori, for every two different-content thought tokens of that thinker, that they differ in content.

## Explanation

In Boghossian's slow-switching thought experiment, a thinker unknowingly moved between Earth and Twin Earth combines an older Earth memory with a newer Twin-Earth perception in a single syllogism. If that inference secretly equivocates between two environment-dependent ("wide") contents without the thinker being able to tell from the inside, then thinkers cannot always know from reflection alone when two of their thoughts have different meanings. That directly collides with Transparency of Difference of Content—the thesis that whenever two of your thoughts mean different things, you can know a priori that they do.

## Usage in Literature

### Classical Argument

[[Paul Boghossian]] (`A-01`; [[Boghossian 1994 - The Transparency of Mental Content]], pp. 37–40, 45) uses this derivation conditionally on two-concept externalism (`ARG-01`), while [[Jessica Brown]] (`A-12`; [[Brown 2004 - Anti-Individualism and Knowledge]], pp. 166–170) and [[John M. Collins]] (`A-13`; [[Collins 2008 - Content Externalism and Brute Logical Error]], pp. 551–555) endorse its premises unconditionally to refute [[Transparency of Difference of Content]] (`P-11`):

1. Possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise.
2. If a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents.
3. If both (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise) and (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents), then it is not the case that every thinker can know a priori, for every two different-content thought tokens of that thinker, that they differ in content.
4. Both (possibly, a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise) and (if a slow-switched thinker performs a subjectively valid syllogism combining a pre-switch memory premise with a post-switch experiential premise, then that thinker commits an introspectively undetectable equivocation between distinct wide contents).
5. Therefore, it is not the case that every thinker can know a priori, for every two different-content thought tokens of that thinker, that they differ in content.

### Premise Rejections and Replies

- **Rejecting `P-47` (Anaphoric univocality):** [[Stephen Schiffer]] (`A-02`; [[Schiffer 1992 - Boghossian on Externalism and Inference]], pp. 32–36) and [[Tyler Burge]] (`A-05`) deny that Peter's syllogism equivocates, arguing independently via anaphoric preservative memory (`D-22`, [[Schiffer Univocal Intent Blocks Slow-Switch Equivocation]], `ARG-06`) that the middle term remains univocal across both premises.
- **Rejecting `P-47` (Single-context metasemantic weighting):** [[Henry Jackman]] (`A-07`; [[Jackman 2015 - Externalism, metasemantic contextualism, and self-knowledge]]) denies slow-switch equivocation via Jackman Single-Context Refutation of Peter Equivocation ([[Jackman 2015 - Externalism, metasemantic contextualism, and self-knowledge#Arguments]]), holding that a single reasoning context assigns uniform content across the syllogism.
